# 五方入味 · 本地互动原型

## 启动

使用支持 ES Modules 的现代 Node.js（建议 Node 22 或更新版本），在本目录执行：

```sh
npm install
npm start
```

- 电脑预览：http://localhost:3000/
- 手机输入：http://电脑局域网地址:3000/join
- 独立装置：http://localhost:3000/screen

预览页展开「现场连接与显示设置」后可选择电脑网卡地址并显示二维码。手机与电脑必须处于可互访的同一局域网；如系统询问，请允许 Node 的本地网络连接。访客 Wi-Fi 隔离、VPN 或防火墙可能影响连接。网络地址变化后重启服务。

## 已确认的设计

- 16:9 横屏，实体宣纸放在屏幕后，中部半高。
- 城市名字由网页绘制；采用抽象生成笔墨，不使用预制动画视频。
- 手机一屏选择城市和 1–2 个词，不显示菜茶名。
- 6 秒一笔，最多 12 笔等候。手机显示送达或排队反馈；断线自动重连，不自动重发未确认的输入。
- 残墨约 3 分钟内消散；不存储，刷新清空历史残墨。若当前仍在播放，则重连同步正在播放的一笔。
- 同一服务器的装置页面共享实时输入，但待机粒子各自运行。

## 显示与校准

电脑预览含模拟纸底；真实屏幕测试时取消「模拟宣纸」。宣纸高度可调整为 30–70%，中心保持不变。城市按纸面比例定位。独立装置页按 H 显示/隐藏设置，双击全屏。城市名字字号可调为默认的 60–200%，漂浮与聚集粒子大小可调为 50–300%，实时生效，不改变水墨笔触粗细。设置是当前页面临时状态，刷新恢复默认。

白、黑、透明背景仅用于设备测试；网页 alpha 透明不保证 Holory X 的物理透明效果。需实际确认设备输入、黑色可见度、背景与纸张间距。目前没有完成 Holory X 实测。

字体使用系统楷体回退，Mac 与 Windows 的字形可能不同；无需互联网字体。后续可选定有授权的字体文件以统一展示。

## 验证

```sh
npm test
```

验证输入约束、味觉参数、静态路由、屏幕离线提示、实时投递、排队和重连同步。现场还需验证真实手机扫码、断网恢复、多人连续提交及屏幕长期运行。
