# 五方入味 · 本地互动原型

## 启动

使用支持 ES Modules 的现代 Node.js（建议 Node 22 或更新版本），在本目录执行：

```sh
npm install
npm start
```

- 电脑预览：http://localhost:3000/
- 手机输入：http://电脑局域网地址:3000/join
- 独立装置：http://localhost:3000/screen

预览页展开「现场连接与显示设置」后可选择电脑网卡地址并显示二维码。手机与电脑必须处于可互访的同一局域网；如系统询问，请允许 Node 的本地网络连接。访客 Wi-Fi 隔离、VPN 或防火墙可能影响连接。网络地址变化后重启服务。

## 已确认的设计

- 16:9 横屏，实体宣纸放在屏幕后，中部半高。
- 城市名字由网页绘制；采用抽象生成笔墨，不使用预制动画视频。
- 手机一屏选择城市和 1–2 个词，不显示菜茶名。
- 6 秒一笔，最多 12 笔等候。手机显示送达或排队反馈；断线自动重连，不自动重发未确认的输入。
- 客人正式提交的笔触在动画结束后留下永久淡墨，保存到现场电脑；刷新和重启自动恢复。当晚作品保留到操控者开始新一场。待机动画和涟漪不进入作品。
- 同一服务器的装置页面共享实时输入，但待机粒子各自运行。

## 显示与校准

电脑预览含模拟纸底；真实屏幕测试时取消「模拟宣纸」。宣纸高度可调整为 30–70%，中心保持不变。城市按纸面比例定位。独立装置页按 H 显示/隐藏设置，双击全屏。城市名字字号可调为默认的 60–200%，漂浮与聚集粒子大小可调为 50–300%，实时生效，不改变水墨笔触粗细。山水开关、纸张高度、城市字号由现场电脑保存并同步到显示页及下载作品；模拟纸底、粒子大小和涟漪仍为当前页面临时状态。

白、黑、透明背景仅用于设备测试；网页 alpha 透明不保证 Holory X 的物理透明效果。需实际确认设备输入、黑色可见度、背景与纸张间距。目前没有完成 Holory X 实测。

字体使用系统楷体回退，Mac 与 Windows 的字形可能不同；无需互联网字体。后续可选定有授权的字体文件以统一展示。

## 验证

```sh
npm test
```

验证输入约束、味觉参数、静态路由、屏幕离线提示、实时投递、排队和重连同步。现场还需验证真实手机扫码、断网恢复、多人连续提交及屏幕长期运行。

### 操控者持续水墨涟漪

显示设置的「持续水墨涟漪」下拉菜单可选择五座城市之一，或关闭（默认）。指定城市持续向外漾开不规则淡墨涟漪；切换城市立即转移，关闭立即停止。设置作用于当前显示页，刷新恢复关闭。手机选城不触发或改变涟漪，味觉提交仍按原流程播放。

### 淡水墨山水背景

使用用户提供的山水图片作为本地素材，以 8% 不透明度、灰度与柔焦低对比效果叠在纸底上、城市与动画下方，弱化具体山石纹理。两个显示设置面板均有「显示水墨山水」开关，默认开启；由现场电脑保存并同步至下载作品，刷新后恢复保存的选择。无需外部图片服务。

### 自然流动的湿墨（2026-10）

参考 [AquaInkGL](https://github.com/WishMelz/AquaInkGL) 的平流、旋涡和耗散思路；其 README 致谢 PavelDoGreat/WebGL-Fluid-Simulation。本次未复制该仓库的代码或资源（检查时未发现明确许可证）。`public/fluid.js` 是独立编写的小范围二维流场：速度平流、压力松弛、墨浓度输运与稀释，Canvas 2D 灰度合成，并非直接移植 AquaInkGL 的完整 WebGL 引擎。

操控者涟漪使用周期性径向注墨与切向水流，墨边会自然拉伸、回卷和消散。落笔保留干笔结构，叠加沿笔锋注入的流动湿墨；五种味觉继续影响浓度、速度、宽度及飞白。流场以 30Hz 固定步长更新，后台恢复不补算大量历史帧。动态湿墨淡去后留下按同一随机种子重建的干墨痕迹，刷新可恢复整晚作品。

## 共同作品与下载

- 当前活动数据在 `data/current.json`，先原子写入磁盘，再确认客人提交。包括随机种子、城市、味觉与播放时间，不记录身份信息。`data/` 已从 Git 排除；迁移电脑或备份活动时请另外复制此目录。
- 「保存此刻的风味手卷」在手机页和电脑页提供 3200×1800 PNG，包含浅纸底、城市名、已完成的共同笔触，以及开启时的山水背景。不含实时粒子、涟漪或正在播放/排队的笔触。当前浏览器系统字体可能因设备略有差异。
- 下载在浏览器本地绘制；无需云服务。无法自动下载的手机可点击「打开图片，长按保存」。仅在能连接现场服务器时获取最新作品。
- 屏幕与导出使用共同的种子化留痕绘制模块；墨层最高不透明度为 52%，避免密集提交无限变黑。已完成作品缓存绘制，无须每帧模拟整晚湿墨。
- 现场电脑通过 localhost 打开的显示设置提供「开始新一场」，需确认；等待落笔队列结束后可开始。旧场次记录保存到 `data/session-<活动ID>.json`，当前画面清空。客人的局域网连接无权开始新场或修改作品设置。
- 意外关机期间已经超过预定播放结束时间的已接受笔触，会直接作为完成笔触恢复，不重新播放。
- 本次功能启用前已经消失的历史笔触没有存档，无法追溯恢复。

## 界面语言

电脑预览页、手机参与页顶部及装置显示设置提供简体中文、繁體中文、English。首次根据浏览器语言选择，手动选择仅保存在该设备/浏览器的本地存储，不修改其他客人的语言。切换保留已选城市和味觉，不刷新、不重复提交。提示、排队反馈、下载状态、确认框和显示设置随语言切换。英文味觉分别为 Light / Rich / Umami / Gentle / Bold；界面城市名称译为英文，画作与导出的五城中文书法保持原样。语言资源本地提供，不依赖在线翻译。
